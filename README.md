<h1 align="center">Field Manager for Craft CMS</h1>

Field Manager is a Craft CMS plugin that helps developers and administrators keep large Craft field collections under control. Clone proven configurations, find fields that are no longer attached, and move field definitions between projects with reviewable JSON.

A carefully configured field is a terrible thing to rebuild from memory. Clone one field or an entire group, then change the details that make the new version different.

## Features

- Clone a field as the starting point for a new one.
- Clone a whole field group in one step.
- Identify fields that are not currently attached to element layouts.
- Export selected fields or whole groups as JSON.
- Import exported JSON into another project and choose the destination group.
