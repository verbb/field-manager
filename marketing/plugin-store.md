Field Manager helps developers and administrators keep large Craft field collections under control. Clone proven configurations, find fields that are no longer attached, and move field definitions between projects with reviewable JSON.

A carefully configured field is a terrible thing to rebuild from memory. Clone one field or an entire group, then change the details that make the new version different.

## Features

- **Clone fields:** Use an existing field configuration as the starting point for a new one.
- **Clone groups:** Repeat a related collection of fields in one operation.
- **Find unused fields:** Identify fields that are not currently attached to element layouts.
- **JSON exports:** Package selected fields or whole groups in a portable format.
- **Reviewed imports:** Bring exported definitions into another project and choose their destination.
- **Bulk selection:** Work with several field definitions together instead of one screen at a time.
- **Know what is still used:** Find fields no longer attached to a layout, then export proven definitions as reviewable JSON when they belong in another project.
